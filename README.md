# bluffing-trivia

Гра включає 2 обов'язкові ролі: ведучий та гравець.
1. Гравець підключається по коду кімнати, який створив ведучий.
2. Ведучий при створенні кімнати вводить пароль, який необхідний для подальшого підключення до цієї кімнати (режим адміністратора).

Права ролі гравець:
- Вказати свій нікнейм
- Вписувати відповідь під час фази збору варіантів відповідей
- Голосувати за варіанти (окрім свого) під час фази голосування

Права ролі ведучий:
- Додавати/редагувати та видаляти запитання (вручну та CSV-імпорт)
- Змінювати порядок запитань
- Переключатися між запитаннями (кнопки та список)
- Змінювати час на збір відповідей та голосування
- Змінювати фазу гри
- Демонструвати варіанти відповідей, авторів та голоси учасників на дошці
- Перемикати дошку між режимами "QR-код", "Запитання" та "Рейтинг"
- Переглядати попередні результати відповідей, голосів та таблицю лідерів
- Видалити кімнату

Механіка гри:
1. Ведучий обирає перше запитання, яке відображається на дошці. При переході між запитаннями всі параметри в адмінці (фаза, перемикачі) скидаються.
2. Після ознайомлення учасників із запитанням на дошці ведучий натискає на кнопку "Збір" і автоматично запускається таймер (в секундах), тривалість якого встановлена у відповідному полі. Гравці вводять свої варіанти відповідей.
3. Після закінчення часу, учасники не можуть додавати нові варіанти, а через 3 секунди автоматично активується перемикач "Показати варіанти відповідей", який випадково перемішує і демонструє всі варіанти на дошці учасникам.
4. Після ознайомлення учасників із варіантами відповідей ведучий натискає на кнопку "Голосування" і автоматично запускається таймер (в секундах), тривалість якого ВДВІЧІ МЕНША за встановлений час у відповідному полі. Гравці обирають варіанти відповідей (окрім свого).
5. Після закінчення часу, учасники не можуть обирати варіанти, а через 3 секунди автоматично активується перемикач "Показати авторів та голоси", який з інтервалом в 5 секунд показує біля кожного варіанту (зверху вниз) автора та голоси гравців.
6. Перед переходом до наступного запитання ведучий може показати рейтингову таблицю гравцям.
